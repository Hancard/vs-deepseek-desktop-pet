# deepseek 角色立绘目录

## 如何自定义角色外观

将你的角色图片放到此目录，命名为以下之一（按优先级）：

1. `character.png` — 静态角色立绘
2. `character.gif` — 动态角色立绘（支持 GIF 动画）
3. 通过环境变量指定：`set AIRI_CHARACTER_IMAGE=C:\path\to\your\image.png`

支持的格式：PNG, GIF, JPG, WebP

## 推荐尺寸

- 宽度：200-280px
- 高度：200-350px
- 透明背景（PNG/GIF）效果最佳

## 如果没有图片

会显示内置的 CSS 绘制的默认 Q 版角色形象。
